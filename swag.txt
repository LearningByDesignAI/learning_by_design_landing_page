2. THE LOOP, IN FIVE LINES

   01 The brain ........ data connected once
   02 Skills ........... know-how written once, callable by anyone
   03 Workflows ........ skills chained into jobs that run end to end
   04 Apps ............. every team ships its own tools on the same brain
   05 Metrics .......... every number defined once; then back to 01
   (in parallel, always: token spend, optimized)

4. THE ARCHETYPE CHEAT SHEET

   Tool Collector ....... licenses everywhere, workflows nowhere
   Pilot Graveyard ...... lots of pilots, nothing in production
   Lone Wizard .......... one person is brilliant, everyone asks them
   Dashboard Optimist ... great charts, few users
   Ring Forger .......... building one tool to rule them all
   Calendar Hostage ..... no time to experiment, so nobody does
   Black Box Spender .... paying for AI, nobody knows the return
   Compounder ........... the loop is spinning

5. ONE UNCOMFORTABLE TRUTH

   AI transformation is a human agency problem disguised as a
   technology problem.
